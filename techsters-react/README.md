# Techsters site (React + Vite + Tailwind CSS)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in /dist

Edit content in `src/data.jsx` (WhatsApp number, prices, team, FAQs, testimonials, impact numbers).
Each section is a component in `src/components/`. Design tokens live in `tailwind.config.js`;
the site's custom styles are in `src/index.css`.
